# CS211
Projects created as coursework for CS211 (Computer Architecture) at Rutgers University. Implementation and coding by Sadia Iqbal.

Reverse Polish Notation (RPN) calculator - A C project developed for CS211: Computer Architecture at Rutgers University. This program implements a Reverse Polish Notation (postfix) calculator using a stack. It reads expressions from an input file, evaluates them using stack-based operations, and returns the result as the program’s exit code. 

Ripple Carry Adder - A C project developed for CS211: Computer Architecture at Rutgers University. This program simulates arithmetic operations at the hardware level by implementing a ripple carry adder using one-bit adders. It supports binary addition, subtraction, and multiplication on fixed-width integers without using high-level arithmetic operators (+, -, *).
